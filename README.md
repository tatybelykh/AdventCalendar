# Your Advent Calendar

Зимний адвент-календарь для индивидуальных онлайн-уроков английского. Ученик выбирает одно из восьми окон. Преподаватель ведёт обсуждение, сохраняет ответы и подтверждает завершение урока. Календарь рассчитан на уровень A2–B1. На одно окно можно отвести около 10–15 минут.

## Локальный запуск

Откройте PowerShell в папке проекта и запустите статический HTTP-сервер.

```powershell
python preview.py
```

Откройте [локальное превью](http://127.0.0.1:8173/). Для остановки сервера нажмите Ctrl+C. При следующих запусках используйте тот же адрес, порт и браузер, чтобы видеть сохранённые профили. Календарь использует JavaScript-модули и открывается через HTTP или HTTPS.

## Первый урок

1. Нажмите **Enter the village** или выберите любое окно. Введите имя или псевдоним, уровень и маршрут. В разделе **Cinema choice** можно выбрать фильм для восьмого окна.
2. Выберите **Enter with music** или **Enter quietly**. Кнопка с динамиком открывает громкость и переключатель музыки.
3. Откройте любое окно. У каждого урока своя рождественская комната. Переключайте экраны кнопками **Back** и **Next**. Номера вверху обозначают этапы, счётчик внизу показывает текущий экран. **Useful language** открывает подсказки для A2 и B1, **Teacher notes** — заметки. Можно отвечать устно. У закрытых окон название задания скрыто.
4. Нажмите **Complete & collect**, когда закончите урок. В окне загорится свет, появится отметка, а в коллекции — предмет. В задание можно вернуться.
5. После любых четырёх завершённых заданий в **Cozy Journey** или шести в **Winter Adventure** нажмите на подарок и откройте конверт. Карточку с именем можно скачать кнопкой **Download PNG**. Текст и дата первого раскрытия сохраняются.
6. Добавьте следующего ученика кнопкой **+**. Список наверху переключает профили. Если имена совпадают, рядом видна короткая часть идентификатора.

На телефоне пролистывайте улицу вбок, чтобы добраться до дальних домов. Кнопки доступны с клавиатуры. Escape закрывает диалог и возвращает в городок.

## Профили и резервные копии

Календарь сохраняет данные в localStorage этого браузера. Имена, ответы, заметки и предсказания хранятся на устройстве преподавателя. Ввод текста сохраняется после короткой паузы, остальные изменения — сразу. Статус сохранения виден внизу. Удаление данных сайта или завершение приватного сеанса может очистить профили.

Откройте **Teacher settings**, чтобы поменять имя, уровень, фильм или маршрут, удалить профиль с подтверждением или создать резервную копию. Смена цели сохраняет завершённые задания и полученное предсказание.

- Для переноса одного ученика выберите **Экспорт этого ученика**. Для всего календаря выберите **Экспорт всех профилей**.
- На другом устройстве откройте **Teacher settings → Открыть JSON-копию**. После проверки структуры покажется количество профилей. Для каждого совпадающего ID выберите сохранение обоих профилей или замену конкретного ученика. Изменения применяются кнопкой **Импортировать**.
- Версия формата копии — 1. Экспортируйте копии в отдельную папку личных файлов преподавателя. Перенос между локальным адресом и GitHub Pages также выполняется через экспорт и импорт.
- Если браузер запретил сохранение или закончилось место, экспортируйте резервную копию до закрытия страницы. Если одновременно редактировали календарь в другой вкладке, сохраните копию текущей работы и обновите страницу.

## Музыка и медиа

Фоновый трек **The Midnight Advent** лежит рядом с `index.html` в файле `The_Midnight_Advent.mp3`. Чтобы заменить его своей записью, используйте это имя или обновите путь в `audio.js`. Стартовая громкость — 15%. Включение и громкость сохраняются. При запуске звука задания, видео или песни фон приостанавливается. После обычной паузы или окончания медиа календарь восстанавливает включённый ранее фон. При открытии YouTube фон приостанавливается и возобновляется при возвращении к календарю.

В шаге **Watch and predict** выберите фильм в списке **Film for this student** и нажмите **Open on YouTube** под его названием. Ролик откроется в новой вкладке. Поставьте фильм на паузу в предложенный момент и вернитесь к вопросу на вкладке календаря.

Шесть записей для звуковых коробочек включены в папку `assets`. Источники, лицензии и сведения о проверке песенного задания приведены в [MEDIA.md](MEDIA.md).

## Редактирование

- `lessons.js` содержит тексты уроков, выражения, историю, варианты реплик, описания звуков и фильмов.
- `activities.js` задаёт этапы, вопросы, варианты ответов и обработку упражнений. `room.js` размещает восемь изображений реквизита на общем фоне комнаты.
- `predictions.js` содержит 30 предсказаний. Выданный текст хранится в профиле, поэтому редактирование списка влияет на будущие карточки.
- `app.js` связывает окна, уроки и коллекцию. `profiles.js` отвечает за хранение и проверку копий, `audio.js` управляет проигрывателями. `gift.js` рисует персональную карточку и сохраняет её в PNG.
- `style.css` задаёт общие стили, `rooms.css` — оформление уроков, а `typography.css` — семейства и роли шрифтов. Координаты окон определены относительно всей иллюстрации. При замене фасадов потребуется скорректировать привязку в `app.js`.

## Публикация на GitHub Pages

Поместите файлы сайта в корень выбранного репозитория с сохранением структуры папок. Для этого проекта достаточно статической публикации из ветки. В настройках репозитория откройте **Settings → Pages**, укажите **Deploy from a branch**, выберите ветку с проектом, каталог **/(root)** и нажмите **Save**. После выполнения публикации GitHub покажет адрес календаря. Сборка и переменные окружения не требуются. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Проверки и ограничения

В Microsoft Edge проверены создание двух профилей с одинаковыми именами, изоляция ответов, сохранение после перезагрузки, оба маршрута, смена цели, повторное открытие задания, сохранение предсказания, скачивание PNG, экспорт и импорт. Проверены оба решения при конфликте и обработка повреждённого JSON. Открыты все этапы восьми уроков, проверены остановка звука и возвращение фокуса после Escape. На узком экране проверена горизонтальная прокрутка к восьмому окну.

В календаре также проверены переименование ученика, отмена и подтверждение удаления, предупреждение при недоступном localStorage и относительные пути при открытии сайта из подпапки.

Для YouTube нужен интернет и доступ к сервису. Интернет для сохранения профилей, фоновой музыки, звуковых коробочек и экспорта карточки не требуется при локальном запуске. Ответы в свободной форме обсуждаются с преподавателем. Учитель сам выбирает момент паузы в фильмах.

## Иллюстрации и шрифт

Городок, интерьеры, сокровища, предметы и карточки событий созданы для этого проекта с помощью ImageGen. По присланным образцам подобраны Pinyon Script для декоративной надписи, Gloock для заголовков общих диалогов и Cormorant Garamond для подзаголовков. Для основного текста и элементов управления вне заданий используется Source Sans 3. Для заданий и их вспомогательных окон подключён Bitter. Карточки My Kind of Winter используют фрагменты постера Winter to do list. Шрифты загружаются локально. [Источники и лицензии шрифтов](assets/fonts/SOURCES.md)
